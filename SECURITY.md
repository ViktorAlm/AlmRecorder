# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue.

Use GitHub's **Security** tab and select **Report a vulnerability** to open a private report with
the maintainers. Include the affected version, reproduction steps, potential impact, and any
suggested mitigation. Please allow a reasonable amount of time for investigation before public
disclosure.

If private vulnerability reporting is unavailable, contact
[Viktor Alm](https://github.com/ViktorAlm) through GitHub to arrange a private reporting channel.

## Protect user data

Never attach recordings, transcripts, databases, speaker identities, model output derived from
real conversations, or other user-derived material to a report. Use synthetic reproduction data
and follow the repository's [`PRIVACY.md`](PRIVACY.md) boundary.

## Supported versions

Security fixes target the latest published release and the current default branch. Older builds
may not receive patches.
