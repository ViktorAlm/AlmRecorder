# AlmRecorder 1.1.0

AlmRecorder 1.1.0 is a major local-transcription and speaker-consistency release for Apple Silicon
Macs running macOS 14 or later.

## Highlights

- Adds the optional VibeVoice 4-bit → Whisper Large v3 Q5_0 → Gemma 4 12B Q5_K_M audio-grounded
  quality pipeline. The pipeline preserves VibeVoice timestamps and speaker turns while using
  Whisper as independent transcript evidence and Gemma for conservative disputed-span cleanup.
- Adds durable checkpoints, bounded VibeVoice malformed-output recovery, memory admission, live
  process monitoring, and safe resume behavior for long transcription jobs.
- Improves global speaker reconciliation with cannot-link constraints, reversible identity
  decisions, representative acoustic coverage, backfill persistence, and comparison tools.
- Adds local realtime dictation, library search improvements, MCP privacy controls, transcript
  review/undo, and Finder audio-file opening.
- Bundles the native Whisper, llama.cpp, VibeASR, custom SQLite, vectorlite, and `uv` runtimes while
  keeping all large AI models as explicit user-initiated downloads.

## Install the community build

1. Download `AlmRecorder-1.1.0-community.dmg` and
   `AlmRecorder-1.1.0-community.dmg.sha256` from this release.
2. In Terminal, from the download directory, run:

   ```bash
   shasum -a 256 -c AlmRecorder-1.1.0-community.dmg.sha256
   ```

3. Open the DMG and drag AlmRecorder to Applications.
4. Control-click or right-click AlmRecorder and choose Open. If macOS still blocks it, try opening
   it once and then use System Settings → Privacy & Security → Open Anyway within about one hour.

This community build is ad-hoc signed for bundle integrity, but it is not signed with an Apple
Developer ID and has not been notarized by Apple. Only approve the artifact downloaded from this
official release after its checksum passes.

## Model and memory notes

- Models are not bundled and do not download at application startup. Install only the models you
  want from Setup or Settings → Models.
- Standard Whisper transcription works on smaller systems, but the full three-stage pipeline is
  intended for Macs with at least 24 GB unified memory and about 18 GB free disk space.
- Heavy model stages wait instead of launching when the Mac lacks safe memory headroom.
- Gemma audio cleanup is optional. Review its proposed text changes, especially for languages or
  acoustic conditions you have not benchmarked locally.

All transcription, speaker processing, cleanup, embeddings, and search remain on-device.
